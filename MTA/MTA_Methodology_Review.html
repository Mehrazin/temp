How the decay features work

7 days30 days60 days90 days180 days360 days

Half-life d

At age 0: 1

At age d: ½

Short half-lives emphasize recent activity.

Long half-lives retain older activity.

Each decay feature adds the weights of every touch in its interaction group.

What a constraint means

Holding other inputs fixed, increasing count or decay cannot lower the fitted score in a constrained group.

Increasing time since the latest touch cannot raise it.

Explanation notation and equations

v(S) = model prediction with only groups in S retained

G all groups   M number of groups
S a subset of G   g one group

v(∅) prediction at the reference input
sg signed contribution of group g

Group Shapley

sg = ΣS⊆G∖{g} |S|! (M − |S| − 1)!M! [v(S ∪ {g}) − v(S)]

Group removal

sgremoval = v(G) − v(G ∖ {g})
MULTI-TOUCH ATTRIBUTIONAppendix 13

Credit equations

q a conversion   g an interaction group
sqg signed contribution score

aqg allocated fraction
uq unattributed fraction

P is total positive score. N is total negative magnitude.

Pq = Σg max(sqg, 0) Nq = Σg max(−sqg, 0)

Positive only

aqg = max(sqg, 0) / Pq
uq = 0

If Pq = 0, set uq = 1.

Negative residual

aqg = max(sqg, 0) / (Pq + Nq)
uq = Nq / (Pq + Nq)

If Pq + Nq = 0, set uq = 1.

Allocated fractions plus the unattributed fraction sum to one conversion.
