Leave-one-group-out · comparator

dg = v(G) − v(G ∖ {g})

Switch off one group; keep the model fixed.

Groups: channel, or channel × LOB / type

Attribution options

Main option

Negative residual

ag = φg+ / (P + N)
u = N / (P + N)

Positive only

ag = φg+ / P   ;   u = 0

Signed net

ag = φg / (P − N)

P = Σ φg+   ·   N = Σ max(−φg, 0)
φg+ = max(φg, 0) · a = credit · u = unattributed

Signed net: negative percentages allowed; net credit = 100%.

v(S): prediction with groups S retained · G: all groups · Sπ,g: groups before g in order π
